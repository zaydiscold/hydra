# Hydra 1.5.1 Patch Release

Date: 2026-06-02
Baseline: `v1.5.0`

## Summary

Hydra `1.5.1` is a focused Account Generator rescue. It fixes the signup path
that could appear stuck at `waiting_for_otp_screen` when OpenRouter/Clerk showed
human verification or a shifted OTP form.

## Changes

- Detects browser-side human verification immediately during Generator signup
  instead of waiting for the full 30-second OTP timeout first.
- Reports `manual_verification` honestly while the isolated browser is blocked
  on CAPTCHA, Cloudflare, or a similar upstream security gate.
- Broadens OTP field detection to Clerk segmented fields, single six-digit code
  inputs, `name/id/aria/placeholder` code fields, and numeric input-mode fields.
- Fills segmented and single-field OTP layouts correctly before clicking the
  visible Clerk submit control.
- Submits Generator OTP from the renderer without raising the global app loading
  veil, so the page stays responsive while browser completion continues.
- Cleans up Generator page copy and replaces the bracketed verify label with a
  normal **Submit code** button.
- Documents the root cause and reproducible behavior in
  `docs/recon/GENERATOR_OTP_TIMEOUT_AND_MANUAL_VERIFICATION.md`.

## Manual Boundary

No supplied signup password was used to create a live upstream account during
verification. The final OpenRouter OTP and human-verification step remains
operator-owned.
