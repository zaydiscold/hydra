# Hydra 1.5.9 Patch Release

Date: 2026-06-02
Baseline: `v1.5.8`

## Summary

Hydra `1.5.9` is a small public-release hygiene and visual polish patch. It
keeps the `1.5.8` Generator, Touch ID, and splash work intact while making the
GitHub release pages harder to ship blank and keeping the tiny moons around the
Jupiter-like sidebar planet moving after the app settles.

## Changes

- Backfills the `v1.5.8` release notes with final hosted evidence: commit,
  CI, Docker, release workflow, public asset list, local ARM package version,
  package smoke, codesign, and zip hash.
- Audits the full `v1.5.x` release line through the GitHub API and records
  line/bullet counts in `docs/RELEASE_AUDIT.md`.
- Updates `.github/workflows/release.yml` so future tag releases create or edit
  the GitHub release body from `docs/releases/<version>.md` when that file
  exists, instead of creating an empty release and only uploading artifacts.
- Adds workflow-contract coverage for the release-notes handoff so the blank
  `--notes ""` fallback cannot silently become the primary path again.
- Keeps the Jupiter-like sidebar planet's moon cluster animating after the
  launch ambient-motion window settles.
- Gives each tiny orbit different CSS-only ellipse geometry: duration, delay,
  tilt, squash, distance, and moon size vary so the motion feels less
  mechanical.
- Preserves `prefers-reduced-motion: reduce` by freezing those decorative
  orbits without removing the planet artwork.
- Documents the ambient planet design choice in
  `docs/DESIGN_ENGINEERING.md`.
