# Hydra 1.5.9

Date: 2026-06-02
Baseline: `v1.5.8`

## Summary

Hydra `1.5.9` is a release-surface and ambient-graphics polish patch.

## Changes

- Uses checked-in `docs/releases/<version>.md` files when creating or editing
  GitHub releases, so future desktop releases do not publish with blank notes.
- Backfills the `1.5.x` GitHub release line with human-readable notes.
- Keeps the Jupiter-like planet's small moon cluster moving after the startup
  ambient window settles.
- Gives each moon a different CSS-only ellipse: duration, delay, tilt, squash,
  distance, and size vary.
- Preserves `prefers-reduced-motion` by freezing decorative orbits without
  removing the planet artwork.
- Documents the ambient planet design choice in `docs/DESIGN_ENGINEERING.md`.

## Notes

This patch does not change account credentials, OpenRouter behavior, or Touch ID
approval semantics.
