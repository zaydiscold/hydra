# Hydra 1.5.7 Patch Release

Date: 2026-06-02
Baseline: `v1.5.6`

## Summary

Hydra `1.5.7` is a narrow Account Generator rescue. It fixes the local
OTP-submit path that could look frozen after the operator entered a six-digit
code, removes the high-cost local limiter from OTP verification, and keeps the
Generator UI from showing stale OTP controls after the browser task has moved
into finalization.

The upstream OpenRouter/Clerk human-verification and email-code ownership
boundaries remain intact. Hydra now makes the local handoff clearer and more
responsive while the isolated browser completes the real session capture and
management-key bootstrap work.

## Changes

- Removes `highCostRouteLimiter` from `POST /api/generator/verify/:taskId`.
  Generator starts remain high-cost limited; submitting an OTP for an already
  running task is not treated as another expensive account-creation launch.
- Validates submitted OTPs as exactly six digits in the controller before the
  browser finalization path starts.
- Moves the renderer to `submitting_otp` optimistically before the quiet
  verification request returns, so Enter/Submit gives immediate visible
  feedback instead of leaving the form grey and ambiguous.
- Blocks stale OTP checkpoint rendering once the task is in finalization or a
  terminal state. A late `checkpoint.state=otp` can no longer keep the OTP form
  visible after submit.
- Makes duplicate OTP submits idempotent while finalization is already running.
  A second click/Enter returns success with "OTP is already being processed."
  instead of racing the browser state.
- Records `otpAcceptedAt` metadata when the server accepts a code, which gives
  logs and future diagnostics a concrete timestamp for the handoff boundary.
- Adds static regression coverage for the route limiter contract, strict OTP
  schema, optimistic renderer state, finalization-state OTP hiding, idempotent
  server submit, and `otpAcceptedAt` metadata.

## Manual Boundary

This patch fixes Hydra's local OTP handoff and responsiveness. It does not
claim to bypass upstream security checks, retrieve the email code, approve
Turnstile/CAPTCHA, approve Touch ID, or complete a real account signup without
operator action.
