# Hydra 1.5.7

Date: 2026-06-02
Baseline: `v1.5.6`

## Summary

Hydra `1.5.7` fixes Generator OTP submission so entering a code feels immediate
instead of frozen.

## Changes

- Removes the high-cost local limiter from OTP verification for an already
  running Generator task.
- Validates submitted OTPs as exactly six digits before browser finalization.
- Moves the renderer to `submitting_otp` as soon as the local request starts.
- Hides stale OTP controls once finalization begins.
- Makes duplicate OTP submits idempotent while the browser is already finishing.
- Records `otpAcceptedAt` metadata when the server accepts a code.

## Notes

Generator starts remain protected; only the follow-up OTP submit was made lighter.
