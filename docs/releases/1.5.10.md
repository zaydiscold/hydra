# Hydra 1.5.10

Date: 2026-06-02
Baseline: `v1.5.9`

## Summary

Hydra `1.5.10` cleans up the public release pages and fixes the ambient space
motion regressions reported after `1.5.9`.

## Changes

- Rewrites the recent GitHub release bodies as concise change notes instead of
  long audit logs.
- Removes awkward consent wording from release notes and Generator status copy;
  the app now describes that step as a required signup checkbox.
- Keeps shooting stars active after the startup ambient window settles.
- Stops the starfield twinkle from translating the full background layer, which
  removes the visible one-frame upward jump.
- Adds faint elliptical orbit guides and GPU-stable transforms to the planet
  moons so they read as actual bodies circling the planet.
- Updates design documentation for the persistent meteors, opacity-only
  starfield, and refined moon-orbit treatment.

## Notes

This is a small visual/copy patch on top of the `1.5.x` desktop refinement lane.
