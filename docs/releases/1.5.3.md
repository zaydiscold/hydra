# Hydra 1.5.3 Patch Release

Date: 2026-06-02
Baseline: `v1.5.2`

## Summary

Hydra `1.5.3` is a focused Account Generator patch. It fixes the browser signup
path that could still look stuck at `waiting_for_otp_screen` and fail with
Playwright's default `Timeout 30000ms exceeded` message instead of showing the
real browser state.

## Changes

- Passes Playwright `waitForFunction` timeouts in the correct third-argument
  options slot, avoiding accidental fallback to the default 30-second timeout.
- Records a sanitized Generator checkpoint for the browser signup page:
  signup form, blocked signup fields, security/manual verification, or OTP
  screen.
- Surfaces that checkpoint in the Generator active-job panel as a compact
  browser-state line.
- Adds a **Show account browser** action backed by
  `POST /api/generator/:taskId/focus`, so the isolated browser can be brought
  forward during manual verification or OTP handoff.
- Keeps the OTP submit path quiet and background-owned while the browser
  completes session capture and management-key provisioning.
- Adds static regression coverage for the explicit Playwright wait signature,
  the focus endpoint, and the Generator browser-state UI.

expose a capturable Hydra window (`noWindowsAvailable`, then `cgWindowNotFound`)
and macOS blocked one System Events window-count request for assistive access.
The fix was still verified through source smoke, package smoke, static renderer
source-map inspection, and LaunchServices process/quit evidence. Final
operator-facing visual review of the active Generator card remains manual on
this machine.

## Manual Boundary

The live smoke stops at OpenRouter's upstream security/manual-verification
boundary. Hydra can now get the isolated browser to the correct state, report
that state in the app, and refocus the browser. Completing the human check,
receiving the email code, and entering the OTP remain operator-owned.
