# Hydra 1.5.3

Date: 2026-06-02
Baseline: `v1.5.2`

## Summary

Hydra `1.5.3` fixes the Generator browser-state handoff that could still report
a generic Playwright timeout instead of the actual signup page state.

## Changes

- Passes Playwright wait timeouts in the correct options slot.
- Records sanitized checkpoints for signup form, blocked signup fields,
  security/manual verification, and OTP screen state.
- Shows that checkpoint inside the Generator active-job panel.
- Adds **Show browser** so the isolated signup browser can be brought forward
  during verification or OTP handoff.
- Keeps OTP submission quiet and background-owned while the browser completes
  session capture and management-key provisioning.

## Notes

The operator still completes any upstream security step and supplies the OTP.
