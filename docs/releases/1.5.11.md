# Hydra 1.5.11

Small runtime-truth patch for the packaged desktop app and CLI.

## Changed

- Packaged Electron now writes a non-secret `hydra-runtime.json` file with the
  live embedded server port, owner PID, local UI URL, and `/v1` proxy URL.
- `hydra doctor`, `hydra status`, `hydra proxy status`, `hydra ai chat`, and
  `hydra stop` now use that runtime file when no explicit port/base URL is
  supplied, so the CLI no longer assumes `localhost:3001` while the packaged app
  is actually listening on an OS-assigned port.
- Runtime-port detection ignores dead-owner stale files and still honors
  explicit `HYDRA_PORT`, `PORT`, `HYDRA_BASE_URL`, `--port`, and `--base-url`
  overrides.

## Fixed

- Fixed false “port closed” reports from `hydra doctor --json` and related CLI
  status commands against a healthy packaged Hydra app.
- Kept the accepted app-shell ambient visuals from `1.5.10`: finite diagonal
  shooting stars and lightweight stepped moons around the Jupiter-like planet.
