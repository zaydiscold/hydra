# Hydra 1.5.5 Patch Release

Date: 2026-06-02
Baseline: `v1.5.4`

## Summary

Hydra `1.5.5` is a narrow Account Generator handoff repair. The previous
release fixed OpenRouter's current signup modal fields; this patch fixes the
next boundary where the isolated browser can reach a code-entry state while
Hydra still reports a `30000ms` OTP-screen timeout or renders the active job
controls too tightly.

## Changes

- Expands OpenRouter/Clerk OTP detection beyond the old one-time-code selector:
  renamed `otp`, `code`, `digit`, and `verification` fields are recognized.
- Detects segmented one-digit OTP boxes, single six-digit numeric inputs, and
  current text such as "we sent a code", "six-digit", and "resend code".
- Extends the browser OTP-screen wait from `30s` to `75s` so normal upstream
  latency does not immediately become a failed generator job.
- Opens the isolated account browser at a stable `1360x900` viewport and screen
  so OpenRouter's Clerk modal and buttons render in the desktop layout.
- Reworks the Generator active-job status shell, OTP input row, and action
  buttons so "Show account browser", "Submit code", and "Cancel job" keep even
  sizing while the task continues in the background.
