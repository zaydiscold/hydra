# Hydra 1.5.5

Date: 2026-06-02
Baseline: `v1.5.4`

## Summary

Hydra `1.5.5` improves the Generator handoff after the signup form advances, so
the app recognizes more OTP-screen variants and keeps the active job UI usable.

## Changes

- Expands browser OTP detection for renamed code fields, segmented inputs, and
  email-code copy variants.
- Waits longer for the OTP screen before treating the browser task as stuck.
- Opens the isolated browser at a stable desktop viewport for easier manual
  verification.
- Keeps Generator active-job actions aligned and easier to click.
- Shortens the visible action label to **Show browser**.
- Keeps browser cleanup tied to the task lifecycle.

## Notes

Hydra watches and reports the signup handoff; the actual email code remains
operator-owned.
