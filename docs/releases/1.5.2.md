# Hydra 1.5.2 Patch Release

Date: 2026-06-02
Baseline: `v1.5.1`

## Summary

Hydra `1.5.2` is a focused follow-up for the Account Generator. It updates the
browser signup lane for OpenRouter's current sign-up form, which now requires a
password and legal consent before the email-code step and may expose a hidden
Turnstile response field before OTP is available.

## Changes

- Fills the OpenRouter signup password when the current form requires it.
- Accepts the required OpenRouter terms/legal checkbox when it is rendered on
  the signup step.
- Fails with a field-specific generator error only when a required password or
  legal field is still blocking the form, so email-first signup variants remain
  possible.
- Detects hidden `cf-turnstile-response`/Turnstile probes as
  `manual_verification` instead of leaving the operator on a blind OTP wait.
- Keeps the manual-verification wait abort-aware, so cancelling or cleaning up a
  Generator task does not log a false launch failure.
- Tightens the Generator OTP row styling so the six-digit field and submit
  button render cleanly in the compact page layout.
- Retries Hydra-owned Playwright profile cleanup briefly to avoid empty temp
  profile residue when Chromium is still flushing after close.
- Expands the recon note in
  `docs/recon/GENERATOR_OTP_TIMEOUT_AND_MANUAL_VERIFICATION.md` with the live
  OpenRouter selectors, redacted reproduction steps, and manual boundary.

## Manual Boundary

The live smoke reached OpenRouter's security-check/manual-verification boundary.
Hydra now gets the browser to the correct state and keeps watching for the OTP
screen, but entering the email code and completing any upstream human
verification remains operator-owned.
