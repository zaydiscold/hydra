# Hydra 1.5.8 Patch Release

Date: 2026-06-02
Baseline: `v1.5.7`

## Summary

Hydra `1.5.8` is a follow-up Account Generator, Touch ID, and splash polish
pass. The live Generator probe showed the browser can fill the OpenRouter signup
modal correctly, then sit behind a hidden Turnstile/loading handoff on
`/sign-up` with a disabled Continue button. Hydra now treats that as a concrete
handoff state, retries the form once the security gate clears, and gives the
operator a safe email-code escape hatch if the isolated browser is already on a
code screen before the detector catches up.

The same patch makes desktop unlock feel intentional on launch: if Touch ID is
available and a valid 24-hour unlock token exists, the login screen starts the
Touch ID release attempt automatically while keeping the password field usable.
The splash was tightened from `16s` to `15s`, with faster Pica-style intro
gravity, a `9.8s` fall window, a `5.2s` portal/light-wave finish, and denser
branching neural ivy behind the card.

## Changes

- Records sanitized `turnstilePending` and loading-button `submitPending`
  checkpoint fields for Generator browser signup jobs.
- Treats a disabled/loading signup submit button as a manual handoff only when
  the button is actually loading or busy, not merely disabled by missing fields.
- Retries the OpenRouter signup form after manual/security verification clears,
  instead of only waiting for the OTP screen forever.
- Allows browser-backed OTP submission from `waiting_for_otp_screen` and
  `manual_verification` when the isolated browser page still exists. This is an
  operator override for “I can see the code field in the browser already.”
- Updates the Generator page to show a deliberate manual-code panel during
  browser/security waits, with cleaner copy and a subtle amber/cyan treatment so
  the fallback does not look like a broken disabled control.
- Adds regression anchors for the post-manual form retry, server OTP override,
  loading-submit detection, and renderer fallback panel.
- Starts the native Touch ID saved-token release automatically from the unlock
  screen when supported, without blocking password entry.
- Debounces renderer token hydration so bootstrap and the visible unlock screen
  cannot trigger overlapping native token requests.
- Updates the native Touch ID reason text to "Unlock Hydra vault with Touch ID".
- Adds a CSS-only unlock backdrop orbit behind the password card that settles
  with the app shell's bounded ambient-motion window.
- Promotes the Jupiter-like sidebar planet's tiny moon cluster from
  launch-bounded motion to continuous, CSS-transform-only motion. Each orbit
  now has its own duration, tilt, elliptical squash, delay, and distance, while
  `prefers-reduced-motion` still freezes the decoration.
- Tightens the packaged splash to `15000ms`, starts the portal at `9800ms`, and
  disposes the Matter world at `17500ms`.
- Increases intro gravity to `1.18` with `0.00128` scale, adds initial downward
  velocity, and shortens the randomized word shower cadence.
- Makes the splash ivy denser and more neural with `11` primary stems, thicker
  kinked branches, faster branch growth, fork nodes, and brighter terminal buds.
