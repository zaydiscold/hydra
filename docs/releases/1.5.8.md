# Hydra 1.5.8

Date: 2026-06-02
Baseline: `v1.5.7`

## Summary

Hydra `1.5.8` polishes the Generator security-handoff path, automatic Touch ID
unlock, and launch splash timing.

## Changes

- Records sanitized loading/security handoff fields for Generator browser signup
  jobs.
- Retries the signup form after manual/security verification clears.
- Allows a browser-backed OTP override when the isolated browser already shows a
  code field.
- Shows a cleaner manual-code panel during browser/security waits.
- Starts the saved-token Touch ID release automatically from the unlock screen
  when supported.
- Debounces native token hydration so bootstrap and the visible unlock screen
  cannot trigger overlapping biometric requests.
- Updates the native Touch ID reason text to **Unlock Hydra vault with Touch ID**.
- Adds a CSS-only unlock backdrop orbit behind the password card.
- Tightens the splash to a faster `15s` sequence with stronger initial gravity,
  a more readable portal/light-wave finish, and denser neural branching.

## Notes

The patch improves local truth and recovery around upstream security checks; it
does not bypass those checks.
