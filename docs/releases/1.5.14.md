# Hydra 1.5.14

## What changed

- Added a hidden meteor-control Easter egg: click the lower-right planet or
  Hydra logo five times to unlock it.
- Added a `P` hotkey that fires extra meteor volleys after the hidden control
  is unlocked, with text fields excluded so typing stays safe.
- Kept Command account balances truthful across list, grid, cards, and map
  labels so fractional OpenRouter credits no longer round up to `$20.00`.
- Kept the restored diagonal shooting-star aesthetic and larger outside planet
  moon orbits from the previous patch lane.

## Verification

- Passed `npm run test:ui-static` with 49 UI/static contract checks.
- The public `v1.5.14` release matrix published Linux x64 AppImage, macOS
  arm64 zip/blockmap, macOS Intel zip/blockmap, Windows NSIS/blockmap, and
  updater metadata.
