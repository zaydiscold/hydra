# Hydra 1.5.14

## What changed

- Reduced the settled meteor loop from near-continuous strikes to one bounded
  strike every `4800ms`, keeping the shooting-star layer alive without holding
  a warm compositor tail.
- Lowered the lower-right planet moon cadence from `184/132/244` orbit steps to
  `40/32/48`, so the moons still move indefinitely on outside paths but do less
  decorative work while idle.
- Kept the hidden five-click space-mode Easter egg and `P` meteor-volley
  hotkey from the `1.5.13` patch.
- Updated the design notes, release audit, and dogfood evidence with the latest
  package hash and idle profile numbers.

## Verification

- Passed `npm run test:ui-static` with 49 UI/static contract checks.
- Passed `npm run lint -- --max-warnings=0`, `npm run gate`, and
  `npm run openapi:hydra`.
- Rebuilt and smoke-tested the macOS ARM package.
- Verified strict deep codesign and bundle version `1.5.14`.
- Packaged asset inspection confirmed the `4800ms` loop and `40/32/48` moon
  steps shipped, while the older high-duty values and `App.meteorPulse` stayed
  absent.
- LaunchServices no-interaction idle profile averaged `0.127%` CPU over five
  minutes with zero stale Hydra Playwright profiles, then native quit returned
  Hydra-owned processes to zero.
