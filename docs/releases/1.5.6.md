# Hydra 1.5.6

Date: 2026-06-02
Baseline: `v1.5.5`

## Summary

Hydra `1.5.6` hardens the Account Generator's signup-shell polling and packaged
desktop capture path.

## Changes

- Replaces the remaining signup-shell wait with short sanitized checkpoint
  polling.
- Records manual-verification state before OTP instead of waiting silently.
- Makes Generator browser sleeps and form helpers abort-aware.
- Keeps packaged cancellation logs tied to the task supervisor reason instead
  of page-close noise.
- Adds an app-owned packaged self-capture path for privacy-safe desktop
  screenshots.
- Documents the packaged capture flow in the dogfood runbook.

## Notes

This release is mainly about making Generator state and packaged visual capture
more reliable.
