# Hydra 1.5.6 Patch Release

Date: 2026-06-02
Baseline: `v1.5.5`

## Summary

Hydra `1.5.6` is a packaged-dogfood and Account Generator follow-up. It keeps
the `1.5.5` Generator OTP repair, removes the remaining brittle signup-shell
wait that could still surface as Playwright's generic `Timeout 30000ms
exceeded`, tightens Generator cancellation cleanup, and adds an app-owned
packaged screenshot path for machines where macOS blocks `screencapture`,
Computer Use, or System Events with Screen Recording / Accessibility
permissions.

## Changes

- Adds an opt-in packaged self-capture launch flag:
  `node scripts/open-packaged-app.mjs release/mac-arm64/Hydra.app --self-capture=/private/tmp/hydra-dashboard.png`.
- Keeps capture out of renderer IPC and preload. The packaged Electron main
  process owns the capture with `webContents.capturePage()` after the real main
  window is revealed.
- Restricts capture output to absolute `.png` paths under the OS temp
  directory, `/tmp`, `/private/tmp`, or Hydra logs, and writes the raw PNG with
  mode `0600`.
- Replaces the Generator browser signup-shell wait with a 500ms checkpoint poll
  that records sanitized signup / manual-verification / OTP state and throws
  `GENERATOR_SIGNUP_SHELL_TIMEOUT` with current page context instead of a blind
  Playwright default timeout.
- Sets packaged Generator browser page defaults to the known startup and OTP
  windows so page-level actions do not silently inherit Playwright's 30-second
  fallback.
- Keeps Generator form fill, terms acceptance, continue-click, hydrate delay,
  and OTP submit delays abort-aware so a cancelled job cleans up as
  `bounded_packaged_handoff_test` instead of a page-closed warning cascade.
- Trims the Generator email alias before starting a job, disables Start for
  whitespace-only aliases, and keeps the active job controls as equal-width
  compact buttons with the shorter **Show browser** label.
- Documents the new dogfood path in the packaged Electron runbook and evidence
  manifest so future screenshot proof does not depend on browser tooling.
- Adds a current `v1.5.6` redacted Dashboard proof:
  `docs/evidence/hydra-v156-packaged-dashboard-self-capture-redacted.png`.

## Manual Boundary

This patch improves packaged screenshot evidence and the Generator handoff to
OpenRouter's current signup shell. It does not bypass upstream human/CAPTCHA
verification, final OTP entry, Touch ID fingerprint approval, route-by-route
desktop review, local Intel-Mac packaging on Apple Silicon, or a real Windows
desktop installer launch.
