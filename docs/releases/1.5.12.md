# Hydra 1.5.12

## What changed

- Restored the lower-right Jupiter-like accent so its small orbiting bodies move again after the app settles.
- Restored the shooting-star layer to the older diagonal local-axis path, so meteors arc across the screen instead of dropping straight down.
- Restored the lower-right planet moons with a lower-duty body-only phase stepper, keeping the guide rings static so the planet no longer looks frozen.
- Kept settled meteors as recurring finite `App.meteorPulse` bursts with the corrected trajectory, instead of an always-on loop that kept the GPU process hot.
- Made Command list/grid balances avoid rounding remaining credits upward, and added balance labels to map nodes.
- Added regression coverage for the meteor transform order, planet orbit steps, Command balance display, reduced-motion handling, and removal of the broken moon timer path.

## Verification

- Built and smoke-tested the macOS ARM package.
- Verified strict deep codesign and bundle version `1.5.12`.
- Profiled the packaged app through LaunchServices for a five-minute idle window: four Hydra-owned processes, zero stale Playwright profiles, and clean native quit.
