# Hydra 1.5.12

## What changed

- Restored the lower-right Jupiter-like accent so its small orbiting bodies move again after the app settles.
- Restored the settled shooting-star layer as finite `45deg` long-tail streaks instead of straight-down, frozen, or sideways-sliding stars.
- Replaced hot continuous moon/meteor CSS loops with low-duty JavaScript scheduling so the visuals stay alive without a persistent compositor burn.
- Added regression coverage for the settled planet orbit tick, meteor pulse scheduler, reduced-motion handling, and removal of the old hot `moonOrbit` path.

## Verification

- Built and smoke-tested the macOS ARM package.
- Verified strict deep codesign and bundle version `1.5.12`.
- Profiled the packaged app through LaunchServices for a five-minute idle window: four Hydra-owned processes, zero stale Playwright profiles, clean native quit, and no old continuous orbit loop in the bundle.
