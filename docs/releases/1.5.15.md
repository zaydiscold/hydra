# Hydra 1.5.15

## What changed

- Removed automatic settled meteor strikes after package profiling showed a hot
  GPU/compositor tail; startup still has ambient meteors, and the hidden meteor
  control keeps the richer user-triggered volley.
- Replaced continuous settled planet-moon animation with low-frequency
  visibility-aware moon phase updates, so the lower-right planet keeps moving
  without a permanent compositor loop.
- Kept hidden meteor control: click the lower-right planet or Hydra logo five
  times, then press `P` to fire extra meteor volleys.
- Updated the README, release audit, and docs index so the public release notes,
  package version, and current source are aligned.
