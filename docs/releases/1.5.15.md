# Hydra 1.5.15

## What changed

- Removed automatic settled meteor strikes after package profiling showed a hot
  GPU/compositor tail; startup still has ambient meteors, and Easter mode keeps
  the richer user-triggered meteor volley.
- Replaced continuous settled planet-moon animation with low-frequency
  visibility-aware moon phase updates, so the lower-right planet keeps moving
  without a permanent compositor loop.
- Kept hidden space mode: click the lower-right planet or Hydra logo five times,
  then press `P` to fire extra meteor volleys.
- Updated the README, release audit, and docs index so the public release notes,
  package version, and current source are aligned.

## Verification

- Passed focused UI/static contracts, integration gate, lint, package smoke,
  strict deep codesign, and `git diff --check`.
- Local macOS ARM LaunchServices idle profile at `t+300s` reported three
  Hydra-owned processes, `0.0%` aggregate CPU, `383.08 MB` RSS, and zero stale
  Hydra Playwright profiles; native quit returned Hydra to zero processes.
- Public release matrix is expected to publish macOS ARM, macOS Intel, Windows,
  Linux, and updater metadata from this versioned source.
