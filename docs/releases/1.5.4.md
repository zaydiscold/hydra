# Hydra 1.5.4

Date: 2026-06-02
Baseline: `v1.5.3`

## Summary

Hydra `1.5.4` repairs the Generator for OpenRouter's current duplicate Clerk
signup modal and floating checkbox portal.

## Changes

- Fills visible first name, last name, email, password, and required checkbox
  fields in the current modal.
- Handles duplicate Clerk form trees by targeting visible matching fields.
- Clicks the visible Clerk Continue control, preferring the modal button over
  background duplicates.
- Adds force-safe and DOM fallback handling for checkbox portals that intercept
  pointer clicks.
- Expands Generator checkpoints with email, name, password, and checkbox
  blockers.
- Allows the OTP panel to unlock when the browser checkpoint proves the OTP
  screen is already visible.
- Fixes the Generator Start button label wrapping.

## Notes

This keeps Hydra aligned with the live signup modal without changing the
operator-owned verification boundary.
