# Hydra 1.5.4 Patch Release

Date: 2026-06-02
Baseline: `v1.5.3`

## Summary

Hydra `1.5.4` is a focused Account Generator repair for OpenRouter's current
signup modal. The live page now renders first name, last name, email, password,
terms, duplicate visible form trees, and a Clerk floating portal around the
checkbox. Hydra no longer treats that state as a stuck OTP wait.

## Changes

- Fills the current OpenRouter signup identity form across the visible modal:
  first name, last name, email, password, and legal acceptance.
- Handles duplicate Clerk form trees by filling visible matching fields instead
  of only the first selector match.
- Clicks the current visible Clerk Continue control, preferring the modal button
  over background duplicates.
- Adds force-safe and DOM fallback terms acceptance for Clerk floating portals
  that intercept pointer clicks on the checkbox.
- Expands sanitized Generator checkpoints with email/name/password/terms
  blockers.
- Lets the Generator OTP panel unlock when the browser checkpoint is already
  `otp`, even if the status poll has not caught up yet.
- Allows backend OTP submission when the task checkpoint proves the OTP screen
  is visible.
- Fixes the Generator Start button label wrapping by replacing the inner
  icon-label span with a Generator-local label class.

## Manual Boundary

OpenRouter's human/security verification remains operator-owned. Hydra now gets
the isolated browser to the correct state, reports that state promptly, and keeps
the local Generator UI ready for the OTP handoff once the upstream check is
complete.
