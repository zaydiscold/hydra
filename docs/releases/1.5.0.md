# Hydra 1.5.0

Date: 2026-06-02
Baseline: `v1.4.9`

## Summary

Hydra `1.5.0` is the desktop operator release: stronger routing visibility,
real Command view modes, tighter account workflows, better density controls, and
more polished launch graphics.

## Changes

- Traffic Console now records model pricing, input/output cost, route outcome,
  attempt number, and cost source for proxy requests.
- The proxy router rotates across more eligible keys with bounded failover,
  clearer exhaustion messages, and `X-Hydra-Attempts` / `X-Hydra-Rotated`
  headers.
- Command now has working Grid, List, and Map modes. Grid/List live inside a
  bounded scrolling account viewport instead of pushing the whole page down.
- Sidebar navigation gained hover labels, stronger proximity motion, a bottom
  Settings control, and a stable rail that does not shrink in Compact mode.
- Pool Manager rows got larger click targets, account-level route toggles, and
  calmer fallback key-paste styling.
- Bulk Import copy is shorter, activity logs persist while navigating, and the
  OTP path is clearly separated from new-account Generator signup.
- Settings added Standard and Compact density modes for the main content area.
- Touch ID defaults on for supported Macs while preserving a password fallback
  and 24-hour saved-token boundary.
- The splash and ambient background gained faster falling glyphs, a longer
  portal/light-wave finish, and a small moon cluster around the Jupiter-like
  planet.
- The database stores cached model prices and request-log cost/attempt fields.

## Notes

This is the minor release that starts the `1.5.x` desktop refinement lane.
