# Hydra 1.5.0 Release Candidate

Date: 2026-06-02
Branch: `feat/v1.5.0-console-polish`
Public baseline: `v1.4.9`

## Summary

Hydra `1.5.0` is an operator-facing refinement release. It makes local routing
easier to trust, gives the desktop more useful density and motion, and removes
several small friction points from the high-frequency account workflow.

This document is the detailed pull-request inventory. Treat `1.5.0` as a
candidate until the hosted Linux, macOS, Windows, Docker, and CI lanes close
green and the branch is merged.

## Routing And Traffic Console

- Replaced the hard-coded three-key proxy retry ceiling with bounded eligible
  key failover: eight attempts by default, configurable with
  `HYDRA_PROXY_MAX_KEY_ATTEMPTS`, clamped to `32`.
- Added truthful exhaustion messages so a tried non-empty key set no longer
  falls through to a misleading "pool empty" response.
- Added `X-Hydra-Attempts` and `X-Hydra-Rotated` response headers.
- Persisted per-row route telemetry: attempt number, outcome, exact total cost,
  and cost source.
- Stored OpenRouter catalog prompt, completion, and request rates with cached
  models.
- Preserved exact OpenRouter `usage.cost` when present.
- Added explicit catalog-estimate fallback for input/output price splits.
- Removed deprecated `stream_options.include_usage` injection; current
  OpenRouter responses already include usage accounting automatically.
- Added Traffic Console route labels and tooltips for served requests, model
  or endpoint `404`s, key cooldown, IP cooldown, exhausted credit, rejected
  keys, upstream `5xx`, timeouts, and network failures.
- Added a visible spend summary and input/output price column.

## Command And Navigation

- Turned Command's Grid, List, and Map controls into real persisted view modes.
- Added a clickable topology map with health-coded account nodes around the
  local Hydra router.
- Kept Account Generator at the bottom of the primary workflow stack.
- Moved Settings beside lock and quit in the bottom sidebar stack.
- Added labeled hover tooltips for collapsed sidebar icons.
- Increased sidebar proximity radius, scale, horizontal pull, and brightness
  response while preserving reduced-motion behavior and owned RAF cleanup.

## Pool Manager

- Rephrased the page subtitle around the real action: choosing which encrypted
  OpenRouter keys Hydra may route through.
- Wrapped key toggles in larger click targets.
- Added an account-level routing toggle that can enable or disable the saved
  keys under one account in one click.
- Replaced the abrasive bright Paste Key treatment with a subdued secondary
  state for rows where manual paste is only an occasional fallback.

## Bulk Import And Density

- Shortened Bulk Import lead copy around the supported direct-HTTPS OTP path.
- Shortened saved-account recovery text.
- Made **Add saved sign-ins** a visible button with a hover explanation.
- Persisted OTP and advanced-relay activity logs in session storage so route
  navigation no longer wipes the operator's recent context.
- Added Standard and Compact UI density controls in Settings.
- Tightened Code Redeemer textarea height and compact-mode spacing.

## Ambient Graphics

- Added a small moon orbit around the Jupiter-like sidebar-background planet.
- Scoped that orbit to the existing launch ambient-motion window, so it stops
  when the app shell settles and is disabled under reduced motion.

## Data Migration

The Prisma migration
`20260602070000_add_proxy_pricing_and_attempt_telemetry` adds:

- `CachedModel.promptPrice`
- `CachedModel.completionPrice`
- `CachedModel.requestPrice`
- `RequestLog.attempt`
- `RequestLog.outcome`
- `RequestLog.totalCost`
- `RequestLog.costSource`

Existing rows remain valid. Legacy Traffic Console rows render as legacy
events until new attempts populate the additional fields.
